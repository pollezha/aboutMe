# Уроки проекта

Пополняется скиллом `/learn`. Формат записи:

```
## YYYY-MM-DD — <коротко>
- Что случилось: <...>
- Причина: <...>
- Правило на будущее: <...>
- Куда закреплено: CLAUDE.md | REVIEW.md | тест | линтер | скилл <имя>
```

Если урок повторился дважды — он должен быть закреплён механически (тест, линтер, хук), а не только текстом.

# Разбор дизайн-концепта: что поправить под цели

Объект: docs/concept/mockup-route-city-v5.html (концепт-арт, не финальный дизайн) · Дата: 2026-10-20
Цели: docs/spec/portfolio-mvp.md · Закрывается на этапе 2 docs/plans/roadmap.md

## Что в концепте уже работает
- **Метафора маршрута совпадает с порядком резюме**: 6 остановок Profile → ProSpace → TimePath → Tech stack →
  Education → Contact. Логистика перекликается с реальным опытом (TMS в ProSpace) и запоминается.
- **Нижняя панель решает 30 секунд почти полностью**: имя, роль, стаж, «Open to work · remote / relocation»,
  Contact, 30-sec summary, Monitoring — HTML, без 3D.
- **Сильный контент**: конкретные цифры (1000+ отправок в день, 40 s → 2 s, 7M+ объектов, ~2×),
  формулировки «результат + как», блок «Proof & links» в каждом окне.
- **Tech stack как серверная**: опыт показан через «где применял и что делал», а не через проценты-полоски.
- **Окна — HTML поверх сцены**, есть `role="dialog"`, `aria-label` у кнопок, базовый `prefers-reduced-motion`.
- **Три темы** заданы через переменные палитры — основа для единых токенов сцены и CSS.

## Что поправить

Приоритет: **блокер** — мешает достичь цели MVP; **важно** — заметно бьёт по метрике; **желательно** — качество.

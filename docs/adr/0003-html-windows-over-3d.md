# ADR-0003: Окна и панель — HTML поверх 3D-сцены

Статус: accepted · Дата: 2026-10-20

## Контекст
Контент (главы, панель, CTA) должен читаться за 30 с, быть доступен с клавиатуры и скринридером
(NFR3, A11y ≥ 95), индексироваться (FR11) и работать без WebGL (FR10). Сцена — украшение и навигация.

## Рассмотренные варианты
| Вариант | Плюсы | Минусы | Стоимость изменения потом |
|---|---|---|---|
| A. Текст и окна внутри 3D (troika-text, меши) | Цельная картинка | Нет доступности и SEO; размытый текст; без WebGL ничего нет | Высокая |
| B. HTML-слой поверх canvas, сцена только навигация | Чёткий текст, нативные диалоги, SEO, тот же UI в 2D-режиме | Синхронизация меток зданий с камерой | Низкая |
| C. Полностью 2D (SVG/CSS) без 3D | Проще и быстрее всего | Теряется концепт и навык 3D | Средняя |

## Решение
B: весь контент — HTML (предрендерен), сцена — отдельный лениво загружаемый слой; 2D-режим использует те же
компоненты окон, поэтому FR10 почти бесплатен.

## Последствия
- Становится проще: доступность, тесты Playwright/axe по DOM, смена дизайна окон без правки сцены.
- Становится сложнее: метки над зданиями — HTML с проекцией координат (cientos `Html`), их нужно
  обновлять при повороте камеры.
- Сигнал пересмотреть: нет.

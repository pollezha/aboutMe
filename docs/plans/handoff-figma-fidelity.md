## Цель
Сайт на 1440, 1280, 768 и 390 в темах day/evening/night и на EN/RU совпадает с макетом Figma: те же элементы на своих
местах, те же цвета (токены), стили текста, тексты, состояния; ничего не потеряно и не добавлено сверх макета.

## Что не совпадает сейчас (разбор 2026-10-25, сверено по кадрам)
**3D-остров (главное).**
- В Figma детальный город из концепт-арта: здания с фасадами и окнами, деревья, кран, бассейн, разметка дорог, фактура
  моря. На сайте — простые цветные коробки на плоской плите (`frontend/src/scene/`).
- Расстановка глав другая: в Figma Profile слева, ProSpace и TimePath сверху, Tech stack справа, Monitoring внизу по
  центру. У нас остров повёрнут иначе (геометрия взята из `docs/concept/mockup-v6.html` → `frontend/scripts/design/scene-layout.json`),
  пина Monitoring в 3D нет.
- Пины в Figma двухстрочные: цветной кружок с номером главы, название, подпись капсом («ProSpace / 2026 · LATEST»).
  У нас одна серая плашка с названием.
- Телефон: в Figma остров заполняет квадрат карты, у нас мелкий (рендер `public/img/island-*.webp`, скрипт `npm run island`).

**Первый экран.**
- Статус в Hero: Figma «Open to work · remote / relocation», сайт «Open to work».
- Подписи метрик Hero: в Figma строчными («shipments / day»), на сайте капсом.
- Остановка 01 в баре: в Figma подсвечена жёлтым по умолчанию, на сайте ни одна.
- Справа сверху: в Figma 2 кнопки (поворот, пауза), на сайте 3 (добавлена 2D/3D).
- Телефон: строка локации в Figma «Remote or relocation in Europe · Serbia · CET».

**Окна глав.** Почти совпадают; отличия: eyebrow на сайте капсом (в Figma обычный регистр), иконка знака серая
(в Figma цвета главы). Остальные 7 окон после этого сверить так же.

## Приёмка каждой задачи
1. Эталон: кадры фреймов Figma задачи в `docs/design/figma-screens/`, ID узлов в брифе исполнителю.
2. Исполнитель кладёт пары `docs/design/compare/<task>/<frame>.figma.png` и `<frame>.site.png`, проходит чек-лист
   `visual-acceptance.md`, обновляет `docs/spec/frontend/<module>.md`.
3. Ты сам открываешь каждую пару картинок и запускаешь `design-reviewer`. Расхождение в рамках задачи — доработка тем
   же агентом; вне задачи — вопрос пользователю. Тесты и `bash scripts/check.sh frontend` зелёные, e2e (`npm run test:e2e`)
   без падений.
4. Коммит задачи включает пары кадров и спеку модуля. Визуальная веха — кадр пользователю до следующей задачи.
